# 손글씨 노트 — 노트 관리·편집 시제품 v0.2

흰 작업 화면 전체를 노트로 사용하는 웹 시제품입니다. 여러 노트와 페이지를 만들고, 종이 크기나 테두리 없이 사방으로 이동하며 계속 필기할 수 있습니다. 부분 지우기, 올가미 편집, 형광펜·직선·화살표, 펜 즐겨찾기, 확대·이동, 화면 고정, 안내선과 자동 저장·파일 백업·불러오기를 제공합니다.

2026년 10월 24일 사용자 요청에 따라 고정 크기 종이를 없애고 무한 캔버스로 변경했습니다. 왼쪽 위 페이지 이름으로 페이지 목록을 열 수 있습니다. 이전 버전의 필기는 첫 노트의 첫 페이지로 옮겨지며 원본 좌표와 내용은 유지합니다.

페이지를 열면 흰 노트가 작업 화면을 채우며 100% 배율로 시작합니다. 배율은 10~100% 범위입니다. ‘10%까지만’이라는 요청은 최소 축소 배율로 해석해 반영했습니다.

PC 동작과 자동 검사를 마쳤습니다. 실제 아이패드의 펜·손가락·손바닥 접촉 확인은 아직 남아 있습니다. 여러 노트·페이지와 백업·복원을 먼저 구현했으며 AI 보정과 연습모드는 아직 구현 전입니다. **오프라인 다시 열기와 위치 북마크는 사용자 요청으로 보류했습니다.**

## 새로 추가한 기능

- **내 노트:** 첫 화면에서 새 노트 만들기, 제목 검색·변경, 최근 사용순 목록과 실제 필기 미리보기. 필기 화면 왼쪽 위 로고를 누르면 돌아옵니다.
- **페이지:** 추가, 이름 변경, 앞·뒤 순서 이동, 복제, 휴지통으로 이동·복구. 마지막 페이지를 지우면 새 빈 페이지를 만들고 지운 내용은 휴지통에 보관합니다. 영구 삭제는 제공하지 않습니다.
- **올가미:** 글씨를 둘러싸 선택한 뒤 안쪽을 끌어 이동하고 오른쪽 아래 손잡이를 끌어 비율을 유지하며 크기를 바꿉니다. 크기 버튼, 전체 선택, 복사·붙여넣기·지우기도 가능합니다. 선택 영역과 닿은 획 전체를 선택합니다.
- **공부 도구:** 반투명 형광펜은 일반 글씨 아래에 그립니다. 직선·화살표는 드래그로 만들고 다른 글씨처럼 부분 지우기·이동할 수 있습니다.
- **펜 즐겨찾기:** 별 버튼에서 펜·형광펜의 색상과 굵기를 최대 8개 저장·적용·제거합니다. 직선·화살표의 색·굵기를 저장하면 펜 설정으로 등록됩니다.
- **백업:** 상단 ‘백업·불러오기’에서 현재 노트 또는 모든 노트를 JSON 파일로 저장합니다. 파일 선택 후 권수·페이지를 확인하고 ‘새 노트로 가져오기’를 누릅니다. 기존 노트는 덮어쓰지 않습니다. 이전 v0.1 내보내기 파일도 지원합니다.

붙여넣기는 이 앱에서 복사한 글씨에 적용되며, 같은 탭에서 다른 노트·페이지로 이동해도 사용할 수 있습니다. 새로고침하면 복사한 임시 내용과 실행 취소 기록은 초기화됩니다. 페이지 전환 중 실행 취소 기록은 페이지별로 유지합니다.

## 컴퓨터에서 실행

1. 이 폴더의 `실행하기.cmd`를 실행합니다. Node.js가 설치된 개발 컴퓨터에서 동작하며 별도 패키지 설치는 필요하지 않습니다.
2. 실행 창이 켜진 상태에서 브라우저로 **http://localhost:4173/** 에 접속합니다.
3. 서버를 끝내려면 실행 창에서 Ctrl+C를 누릅니다.

터미널을 사용한다면 이 폴더에서 다음을 실행합니다.

```powershell
node server.mjs
```

4173 포트가 이미 사용 중이라는 메시지가 나오면 먼저 기존 주소를 열어 확인합니다. 같은 노트를 다시 열 때는 같은 주소·포트·브라우저를 사용합니다.

## 아이패드에서 확인

1. 개발 컴퓨터와 아이패드를 같은 공유기의 네트워크에 연결합니다. 컴퓨터는 유선 연결이어도 됩니다.
2. 컴퓨터에서 서버를 실행한 채로 둡니다.
3. 실행 창의 `Same Wi-Fi:` 주소 중 컴퓨터가 실제 연결된 네트워크 주소를 아이패드 Safari에 입력합니다. 아이패드에서 `localhost`를 입력하면 컴퓨터에 접속하지 않습니다.
4. 첫 필기를 쓰고 상단의 **이 기기에 저장됨** 표시를 확인합니다.
5. 아래 실기 확인 순서로 펜과 손가락을 각각 사용합니다.

네트워크 주소가 여러 개 표시되거나 접속하지 못하면, 표시된 주소와 아이패드의 접속 오류를 기준으로 연결을 확인합니다. 현재는 컴퓨터가 웹 파일을 제공하며 외부 호스팅에 배포하지 않았습니다.

## 조작

| 조작 | 동작 |
| --- | --- |
| 마우스 드래그 | 선택한 필기·편집 도구 사용 |
| Shift + 마우스 드래그 | 고정이 꺼져 있을 때 종이 이동 |
| 마우스 휠 / 아래 +·− | 고정이 꺼져 있을 때 10~100% 범위에서 확대·축소 |
| 100%로 보기 / 페이지 미리보기 | 현재 화면 중심을 유지하며 100% 배율로 열기 |
| 펜 | 손가락 설정·화면 고정과 관계없이 필기 |
| 손가락 필기 켬 | 한 손가락으로 선택한 펜·지우개 사용 |
| 손가락 필기 끔 | 고정이 꺼져 있으면 한 손가락으로 종이 이동, 고정 중에는 무시 |
| 두 손가락 | 고정이 꺼져 있으면 확대·이동. 한 손가락으로 시작된 임시 획은 취소 |
| 화면 고정 | 종이 이동과 확대·축소 차단. 필기는 유지 |
| 무지·줄노트·격자 | 이미 쓴 글씨와 별도로 안내선 변경 |
| P / E / H / L | 펜 / 지우개 / 형광펜 / 올가미 |
| 올가미에서 Ctrl 또는 ⌘ + A / C / V | 전체 선택 / 복사 / 앱 안에서 붙여넣기 |
| 올가미에서 Delete / Backspace | 선택한 획 지우기. 실행 취소 가능 |
| Ctrl 또는 ⌘ + Z | 실행 취소 |
| Ctrl 또는 ⌘ + Shift + Z | 다시 실행 |
| 0 | 100%로 보기 |

노트 제목도 변경할 수 있습니다. 필기·지우기·올가미 편집의 실행 취소는 페이지별 최근 100회까지 보관합니다. 재접속 시 마지막 저장 결과가 복원되며 실행 취소 기록은 새로 시작합니다. 페이지 이름·순서 변경은 필기 실행 취소와 별도입니다.

## 저장 범위

- 원본 획의 좌표·압력·시간, 색·굵기, 지워진 결과, 제목과 입력·안내선 설정, 마지막 화면 위치와 배율을 이 브라우저의 IndexedDB에 저장합니다. 음수 좌표나 기존 종이 범위 밖의 필기도 같은 방식으로 저장합니다.
- 다시 열 때 마지막 화면 중심은 유지하고 배율은 항상 100%로 시작합니다. 이전 버전에서 범위 밖 배율로 저장한 노트도 내용을 유지하며 열립니다.
- 저장이 끝나기 전 새로고침에 대비해 임시 기록을 함께 사용하고, 저장 상태와 실패를 화면에 표시합니다.
- 노트 내용은 서버에 전송하지 않으며 다른 기기와 자동 동기화되지 않습니다.
- 백업은 노트 제목, 페이지 순서·제목·필기·안내선·보기 위치, 휴지통의 페이지, 펜 즐겨찾기를 포함합니다. 가져온 노트와 페이지에는 새 식별자를 부여해 원래 노트와 독립적으로 편집합니다.
- 불러올 파일은 25MB 이하입니다. 파일 전체의 형식을 먼저 확인하므로 잘못된 파일의 일부만 반영하지 않습니다. 큰 전체 백업은 노트별로 나누어 내보냅니다.
- v0.1 자료는 같은 브라우저 저장소에서 v0.2로 한 번 옮깁니다. 이전 저장 기록은 지우지 않으며 새 자료는 별도 키에 저장합니다. 이전 버전으로 되돌리면 v0.2에서 추가한 변경은 보이지 않습니다.
- 현재는 같은 노트를 한 탭에서 사용합니다. 여러 탭의 동시 수정 충돌 처리는 후속 작업입니다.
- 브라우저 데이터 삭제 시 저장된 내용도 없어질 수 있습니다. 중요한 표본은 내보내기로 별도 보관합니다.
- 연결이 끊겨도 이미 열린 화면에서 쓰기·기기 저장은 가능합니다. 서버가 꺼진 상태에서 앱을 새로 여는 오프라인 기능은 이번 개발 범위에서 제외했습니다.

## 아이패드 실기 확인 순서

아래 항목을 통과한 뒤 1단계를 완료 처리합니다. 화면 크기 확인이나 입력 규칙 자동 검사가 실제 기기 검증을 대신하지 않습니다.

1. 펜으로 한글·영문·숫자를 쓰며 끊김과 입력 지연을 확인합니다.
2. 손가락 필기를 끄고 펜으로 쓰며 손바닥을 올렸을 때 획이나 종이 이동이 생기는지 확인합니다.
3. 손가락 필기를 켜서 쓰고, 두 손가락으로 확대할 때 원치 않는 획이 남는지 확인합니다.
4. 확대된 상태에서 글씨 한 획의 가운데만 지우고 펜으로 다시 씁니다.
5. 실행 취소·다시 실행으로 원본과 편집 결과가 올바르게 오가는지 확인합니다.
6. 화면 고정을 켜면 필기는 가능하고 이동·확대는 멈추는지 확인합니다.
7. 안내선을 바꾸어도 글씨 위치가 유지되는지 확인합니다.
8. 저장 완료 뒤 새로고침·Safari 재접속을 해서 결과가 남는지 확인합니다.
9. 여러 노트·페이지를 오가며 올가미 이동·크기 조절·복사·붙여넣기와 형광펜·직선·화살표를 확인합니다.
10. 백업 파일을 저장하고 새 노트로 가져온 뒤, 복원한 글씨 일부를 지우고 수정합니다.

기기 정보는 이때 확인 가능한 만큼 기록합니다. 펜이 손가락 입력으로 인식되면 손가락 필기를 켜서 사용할 수 있지만, 해당 펜과 손바닥의 구분은 제한될 수 있습니다.

## 개발 파일과 검사

- `dist/index.html`, `dist/styles.css`: 화면 구성·반응형 배치.
- `dist/app.js`: 캔버스 렌더링·도구·실행 기록·저장 연결.
- `dist/geometry.js`: 좌표 변환·확대·부분 지우개. 빠른 지우개 이동 경로까지 계산합니다.
- `dist/input.js`: 펜·마우스·손가락 입력 상태 처리.
- `dist/storage.js`: 데이터 형식 확인·자동 저장·미완료 저장 복구.
- `dist/library.js`: 여러 노트·페이지, 휴지통, 이전 데이터 이전, 백업 형식 검사·복원.
- `dist/editing.js`: 올가미 판정·선택 변환·직선·화살표 좌표.
- `dist/painting.js`: 형광펜·일반 글씨 그리기와 미리보기.
- `dist/layout-check.html`: 태블릿·모바일 폭 확인용 개발 화면.
- `tests/core.test.mjs`: 앱과 동일한 입력·기하·저장 선택 함수 검사.
- `tests/library.test.mjs`: 데이터 이전, 페이지 관리, 백업 복원, 올가미 편집, 재접속 후 부분 지우기 검사.
- `server.mjs`: `dist` 폴더만 제공하는 로컬 서버.

```powershell
npm.cmd run check
npm.cmd test
```

압력 값은 보존하지만 첫 버전의 선 굵기는 선택한 굵기로 일정하게 표시합니다. 실제 펜의 압력감이나 획 보정은 아직 추가하지 않았습니다.

참고 API: [Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events), [Using IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB).
